ทำงานในเบราว์เซอร์ของคุณทั้งหมด ไฟล์ไม่ถูกอัปโหลดไปที่ไหน

← กลับหน้าแรก
Word → PDF รูปภาพ → PDF

Word → PDF

รองรับไฟล์ .docx (ไม่รองรับ .doc รุ่นเก่า) การจัดหน้าอาจต่างจากต้นฉบับเล็กน้อย ตัวอักษร ตาราง และรูปภาพจะถูกแปลงให้

ถ้าต้องการให้ PDF เลือกคัดลอกข้อความได้และคมชัดที่สุด ให้ใช้ปุ่ม "พิมพ์ / บันทึกเป็น PDF" แล้วเลือก Save as PDF ส่วนปุ่มดาวน์โหลดจะได้ PDF ที่เป็นภาพ

รูปภาพ → PDF

รวมรูปหลายรูปเป็น PDF ไฟล์เดียว 1 รูปต่อ 1 หน้า (JPG, PNG, WebP ฯลฯ)
